# T-01 Responsáveis e repositórios (feita por uma pessoa)

## Objetivo
Ter quem revise e um lugar protegido para integrar as mudanças.

## Depende de
Nada.

## Escopo
- Registrar o dono do produto e o responsável técnico: @Deeved. Não há substituto.
- Usar o GitHub no plano gratuito, com o GitHub Actions como CI.
- Criar o repositório skillquest com este kit e torná-lo público.
- Criar o repositório privado skillquest-challenges.
- Seguir docs/repository-setup.md.

## Fora do escopo
- Colocar material de desafios no repositório skillquest (ver T-11 no plano).

## Critérios de aceite
1. O dono do produto e o responsável técnico têm nome. A falta de substituto está registrada como risco.
2. Um envio direto ao ramo principal é recusado, inclusive o de um administrador.
3. Uma mudança só entra no ramo principal por pedido de integração. A pessoa lê as mudanças antes do merge.
4. O agente não tem acesso ao repositório skillquest-challenges.

## Risco aceito
O GitHub não exige aprovação neste arranjo (ver docs/repository-setup.md). A leitura antes do merge depende de quem integra.

## Revisão
Pessoa.
