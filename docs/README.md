# Documentos do SkillQuest

Origem: texto aprovado pela pessoa responsável em 28/11/2026, versão do modelo de julgamento.

## Como ler
Nos arquivos de tema, as seções com conteúdo do produto e do projeto trazem o estado no título. Em open-items.md, só a seção “Pendências” lista itens pendentes; as demais são registros. Em proposals.md e archived.md, o próprio arquivo indica o estado. Seções de navegação, como “Veja também”, não têm estado.

- **Decidido**: foi aprovado pela pessoa responsável.
- **Plano**: orienta a construção, mas ainda pode mudar e não conta como decisão aprovada.
- **Pendente**: não deve ser decidido nem completado pelo agente. Lista em [open-items.md](open-items.md).
- **Proposta**: ainda não decidida. Lista em [proposals.md](proposals.md).
- **Arquivado**: fica fora da primeira versão e do piloto. Lista e condições para retomar em [archived.md](archived.md).

Partes do repositório ainda descrevem o modelo antigo, com envio de código. As divergências conhecidas estão em
[open-items.md](open-items.md#divergências-do-repositório).
