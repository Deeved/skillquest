# Primeira versão

## Marco de construção (Plano)
A primeira versão é um marco de construção. Ela não muda o lançamento com 5 trilhas e 15 desafios.

## Primeira versão (Decidido)
- Um único desafio, novo, no formato de julgamento.
- O desafio é testado com 3 a 5 pessoas, em formulário ou documento, antes da construção das telas.
- Resposta na própria tela, sem envio de arquivo e sem execução de código.
- Login com e-mail e senha no piloto.

O desafio de código planejado antes ("A API que aceita tudo") fica arquivado com o módulo de código (veja [archived.md](archived.md)).

## Escopo (Plano)
| Entra | Fica para depois |
|---|---|
| Convite, login e saída | Recuperação automática de senha |
| Painel e página do desafio, com 3 dicas | Outras trilhas e os desafios 2 e 3 |
| Resposta na tela e revisão do agente | Revisão de entregas de QA e PO |
| Assistente com limite de perguntas e bloqueio de gasto | Módulo de código |
| Supervisão: primeira revisão, dúvidas e contestações | Tela para criar e publicar desafios |
| Competência registrada e item de avatar liberado | Editor de avatar (usa um avatar pronto) |
| Mapa de habilidades visível só para a própria pessoa | Escolha de quem vê o mapa |

O plano mantém o desafio novo na trilha Back-end.

## Ensaio do formato (Plano)
Observar se o desafio parece um problema real, se separa justificativa de chute, se a pessoa aprende algo que possa usar e se a avaliação do agente concorda com a de uma pessoa. A pessoa avalia sem ver antes o resultado do agente. Um grupo pequeno encontra problemas de formato, mas não comprova aprendizado.
